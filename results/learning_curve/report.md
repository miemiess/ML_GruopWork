# 学习曲线：训练用户数对跨用户效果的影响

固定 C 与 D 实验的获选配置，只改变参与训练的用户数，在**验证用户**上评分。测试用户不参与。每个人数随机抽取 5 组互不相同的用户组合（种子 42）；全部训练用户只有一种组合，所以只跑一次。

| 训练用户数 | 手势 macro-F1 中位数（范围） | 指力平均 RMSE 中位数（范围） |
| ---: | --- | --- |
| 1 | 0.563（0.520–0.648） | 84.12（80.61–92.98） |
| 2 | 0.649（0.475–0.736） | 78.90（75.91–84.56） |
| 4 | 0.793（0.775–0.805） | 77.98（75.12–83.84） |
| 8 | 0.798（0.790–0.813） | 73.90（72.41–79.99） |
| 16 | 0.819（0.808–0.822） | 73.99（71.74–75.31） |
| 全部（手势 22 / 指力 26） | 0.822 | 71.73 |

- **手势**（RMS+MAV+WL、100 棵树随机森林）：从 1 人到 4 人提升最明显，之后逐渐饱和。多数类基线约 0.05。
- **指力**（log_rest、RMS+MAV+WL、随机森林、五窗平滑）：随人数持续下降。只用 1 人时，有 2 组不如同样训练用户的均值基线（约 84–92）；8 人起所有组合都明显优于基线。
- **抽样波动**：训练人数少时，结果很大程度取决于抽到了谁；人数增加后，波动明显收窄。
- **一致性**：全部用户时的结果与原实验验证集上的获选分数一致（手势 0.822，指力 71.73）。

窗口高度重叠，同一人数下只有 5 次抽样，范围仅用于说明波动幅度，不是置信区间。

## 复现

```powershell
.\.venv\Scripts\python.exe -m emginsight.learning_curve
```

需要原始数据和指力特征缓存。本机手势约 10 秒，指力约 8 分钟（含读取缓存）。输出为 [uci_gesture.csv](uci_gesture.csv) 和 [putemg_force.csv](putemg_force.csv)，每次抽样一行，记录所用用户编号。网页“训练过程”的第 2 步读取这两个文件。
