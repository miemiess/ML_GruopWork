# 开发需求清单

这是后续协作开发的完整范围与验收依据，配合[架构约定](architecture.md)和[贡献流程](../贡献.md)使用。原 README 的“实验复现”和“下一阶段”已合并到本清单；复现作为各需求的验收要求保留。

**当前状态：只有基础工作区与规划文档，下面的实现需求均未完成。** 本清单不预先分配个人；进度和负责人统一记录在 [GitHub Issues](https://github.com/miemiess/ML_GruopWork/issues)。表中“认领/进度”打开该编号的搜索结果，没有结果表示尚未建立任务记录；同一编号已有任务时先协调。

## 总体完成标准

- 不使用深度学习。核心算法使用 Python/NumPy 自行实现，scikit-learn 仅作为注明来源的参考。
- 三个独立任务共享架构，不能把不同数据集混成一个标签或直接比较传感硬件优劣。
- 每项需求有明确输入、输出、实现文件、相关测试、配置与文档；数据和实验保留来源、划分、参数与环境。
- 功能通过 PR 合入 main 后，且验收证据齐全，才关闭对应 Issue。纯研究任务也必须提交可追溯结果。
- 数据访问、许可或标签无法满足时，先提交审计证据并记录受阻；由小组确认替代范围，再修改清单和相关依赖，不静默跳过任务。
- 未提供正式课程评分表或期限，本清单是项目工程方案，不擅自增加分数承诺或截止日期。

## 详细要求

<a id="r01"></a>

### R01 公共数据类型与接口契约

**目标：** 把架构文档中的 Recording、SplitAssignment、WindowBatch、FeatureBatch 和模型/变换协议实现为统一类型，供所有模块使用。

**前置：** 无。**主要目录：** src/emginsight/core/contracts.py；tests/unit/core/

**交付物：**

- 实现具名结构、形状与元信息校验，提供最小合成样例。
- 定义数据、配置、未拟合等异常类型；说明字段含义、单位和标签映射。

**验收条件：**

- [ ] 分类与多输出回归样例均可通过契约校验；无标签推理允许 target/y 为 None，训练必须拒绝缺失目标。
- [ ] 时间戳不递增、长度不一致、重复 recording_id、缺少通道单位等错误能定位到字段。
- [ ] 各模块只引用此处公共类型，不另写不兼容的数据对象。

**验证方式：** 验证合法与非法形状、标签映射、时间轴、元信息及单输出回归仍为二维。

<a id="r02"></a>

### R02 配置加载与运行参数校验

**目标：** 以 TOML 描述任务、数据、划分、窗口、特征、模型、评估及输出；同一份配置足以确定运行行为。

**前置：** R01。**主要目录：** src/emginsight/core/config.py；configs/；tests/unit/core/

**交付物：**

- 读取并验证示例中的 schema_version 及字段，解析相对仓库根目录的路径。
- 为三个任务各提供一份经数据审计补齐的配置；先提交加载器时可保留明确标为模板的配置。
- 记录实际生效配置；拒绝未知模型、拼错字段及无效参数。

**验收条件：**

- [ ] TODO、空通道、非正窗口/步长、任务目标不匹配会在训练前失败。
- [ ] 随机种子显式传递，不依赖全局隐式随机状态。
- [ ] 验证路径、目标数与单位；不能用 force 数据配置启动手势任务。

**验证方式：** 合法模板校验策略、无效配置、未知字段、跨平台相对路径和同配置一致性。

<a id="r03"></a>

### R03 UCI 手势数据审计与适配器

**目标：** 读取 UCI 原始记录，核对 8 通道、时间、类别与用户/会话身份，输出统一 Recording。

**前置：** R01。**主要目录：** src/emginsight/datasets/uci_gestures.py；data/manifests/；docs/data_audits/；tests/unit/datasets/

**交付物：**

- 数据审计说明和来源清单：版本、许可、校验值、文件结构、保留人数/类别/排除规则。
- 适配器及小型合成文件测试；实际数据放 data/raw/uci_gestures/。

**验收条件：**

- [ ] 明确标签 0 未标注、标签 1 静息，以及第 7 类覆盖不足的处理。
- [ ] 保留原始标签映射、通道顺序、时间单位与分组身份；不凭空假定采样率。
- [ ] 不在适配器中划分数据、标准化或读取测试结果选样本。

**验证方式：** 列缺失、非法标签、非递增时间、不同记录格式、标签转换与身份保留。

<a id="r04"></a>

### R04 putEMG-Force 数据审计与适配器

**目标：** 读取 emg_force，建立 EMG 与实测力量的一一对应关系，支持明确选择单个或多个力量目标。

**前置：** R01。**主要目录：** src/emginsight/datasets/putemg_force.py；data/manifests/；docs/data_audits/；tests/unit/datasets/

**交付物：**

- 审计准确的 force 子集参与者/会话、列含义、许可、采样信息、力单位和校准/MVC 处理。
- 首版固定一种经验证的 CSV 或 HDF5 格式，说明需要的可选依赖。

**验收条件：**

- [ ] 目标使用实测 FORCE_*，不能以 TRAJ_* 指令轨迹代替。
- [ ] 24 通道与选定力量列对齐，单输出和多输出均返回 (T, O)。
- [ ] 单位不能确认时标记原始单位并限制解释，不能擅写牛顿；缺失试验有统计。

**验证方式：** 目标列选择、缺列、单位记录、时间对齐、(T,1)/(T,O) 形状与异常数据。

<a id="r05"></a>

### R05 Zenodo 疲劳数据审计与适配器

**目标：** 将肌电与自感疲劳评分按时间对齐，形成带有效性掩码的统一记录。

**前置：** R01。**主要目录：** src/emginsight/datasets/zenodo_fatigue.py；data/manifests/；docs/data_audits/；tests/unit/datasets/

**交付物：**

- 审计 v2 数据结构、采样率、时钟偏移、0/1/2 标签、人数、许可和缺失区间。
- 实现明确记录策略的对齐函数与适配器；保留评分原始时刻。

**验收条件：**

- [ ] 根据时间戳处理不同采样率，不按数组行号直接拼接。
- [ ] 不跨缺失区间外推，不把主观疲劳解释为临床诊断。
- [ ] 输出每条记录的有效区间、排除原因和分组身份。

**验证方式：** 不同频率、已知时间偏移、边界、缺失评分、非法等级和无法对齐的记录。

<a id="r06"></a>

### R06 用户与会话分组划分

**目标：** 先在原始记录层面划分，再提供固定的训练、验证和测试记录集合。

**前置：** R01。**主要目录：** src/emginsight/splitting/grouped.py；data/splits/；tests/unit/splitting/

**交付物：**

- 支持 subject_holdout；session_holdout 作为单独标注的协议。
- 保存和重载精确划分文件，包含数据版本、策略、种子和用户/会话/记录标识。
- 支持按明确比例和种子生成分组划分，规定取整规则并保存实际分组；正式实验可直接加载固定划分。

**验收条件：**

- [ ] 用户留出下用户互斥；会话留出下组合键互斥；任何记录不得跨集合。
- [ ] 相同数据清单和种子生成一致划分；数据清单变化后旧划分不能被静默复用。
- [ ] 训练缺类、集合为空或 ID 不存在时明确失败；不用随机分窗替代分组划分。

**验证方式：** 合成多用户多会话数据、重载一致性、组重叠和重复/未知 ID。

<a id="r07"></a>

### R07 记录预处理与滑动窗口

**目标：** 对已经划分和对齐的记录独立处理，输出 WindowBatch，并保持数据来源可追溯。

**前置：** R01、R02、R06。**主要目录：** src/emginsight/preprocessing/windowing.py；tests/unit/preprocessing/

**交付物：**

- 按采样率将毫秒窗口转换为采样点，明确取整规则及尾部不足窗口的处理。
- 提供可配置的记录级滤波/去趋势开关；解释频率与 Nyquist 限制。
- 实现分类标签一致窗口和回归窗口目标均值，统计无效窗口。

**验收条件：**

- [ ] 窗口不跨记录、集合或分类标签变化点；无效采样窗口首版排除并计数。
- [ ] 输出 (N,W,C)、y 及每窗口起止时间、用户、会话、记录。
- [ ] 离线滤波与推理一致；窗口、步长、滤波频率不合法时停止。

**验证方式：** 已知短数组、重叠窗口、尾部、标签切换、无效掩码、不同采样率与零窗口。

<a id="r08"></a>

### R08 时域特征 RMS、MAV 与 WL

**目标：** 提供独立于数据集的确定性窗口特征，输出 FeatureBatch。

**前置：** R01。**主要目录：** src/emginsight/features/time_domain.py；tests/unit/features/

**交付物：**

- 用 NumPy 实现 RMS、MAV、WL，明确沿 W 轴计算和 WL 求和定义。
- 按配置的通道顺序及通道内特征顺序输出列与名称。

**验收条件：**

- [ ] (N,W,C) 输出 (N,3C)，不混淆采样、通道与窗口轴。
- [ ] 所有 y 与分组元信息按原顺序保留；不在此处标准化。
- [ ] 常数、全零和已知波形的数值与手算一致；非有限输入按契约拒绝。

**验证方式：** 手算小矩阵、单通道、多通道、单点窗口 WL=0、形状及列名顺序。

<a id="r09"></a>

### R09 仅训练集拟合的特征标准化

**目标：** 把标准化作为独立可保存的变换，供所有模型与推理共用。

**前置：** R01。**主要目录：** src/emginsight/preprocessing/transforms.py；tests/unit/preprocessing/

**交付物：**

- 实现 fit、transform 和状态导入导出，保存特征名称、均值及缩放因子。
- 按训练集统计量转换验证与测试集。

**验收条件：**

- [ ] 测试输入不改变均值与缩放因子；零方差列缩放因子为 1。
- [ ] 尚未 fit、特征顺序不一致或维度变化时失败。
- [ ] 状态恢复前后输出一致，支持训练折独立实例。

**验证方式：** 训练/测试均值故意不同的数据、零方差、状态恢复和错误列顺序。

<a id="r10"></a>

### R10 简单基线与自定义 kNN 分类

**目标：** 提供公平比较所需的多数类、训练均值基线及 NumPy kNN 分类器。

**前置：** R01。**主要目录：** src/emginsight/models/baselines.py；src/emginsight/models/knn.py；tests/unit/models/

**交付物：**

- 分类多数类基线、可多输出的回归训练均值基线。
- kNN 的 fit/predict/state 接口，明确距离、k、平票规则及批量预测内存策略。

**验收条件：**

- [ ] 参数仅从训练样本获取；k 越界、未拟合、输入维度错误时失败。
- [ ] 分类标签映射保留；重复距离和平票结果可重复。
- [ ] kNN 保存状态包含必要训练特征/标签，模型文件与原始数据一样保存在本地。

**验证方式：** 已知邻居样例、k=1/最大合法值、平票、类别不连续和多输出均值基线。

<a id="r11"></a>

### R11 自定义多分类逻辑回归

**目标：** 实现适用于手势与疲劳的 NumPy 多分类逻辑回归，不调用库模型完成核心训练。

**前置：** R01。**主要目录：** src/emginsight/models/logistic.py；tests/unit/models/

**交付物：**

- 固定并说明 softmax 多分类方案、交叉熵、梯度优化、L2、截距及停止条件。
- 实现数值稳定的概率计算、fit/predict/state 与训练日志。

**验收条件：**

- [ ] 类别映射、种子和超参数可追溯；不对截距施加意外正则。
- [ ] 简单可分数据能学习，损失与梯度有限；梯度经数值差分检查。
- [ ] 与参考实现对比时说明目标函数/正则化差异，不要求不同优化器逐位一致。

**验证方式：** 数值梯度、小型多类数据、极端分数稳定性、未拟合、保存恢复及迭代上限。

<a id="r12"></a>

### R12 自定义岭回归与多输出力量预测

**目标：** 实现 NumPy 岭回归，支持一个或多个实测力量输出。

**前置：** R01。**主要目录：** src/emginsight/models/ridge.py；tests/unit/models/

**交付物：**

- 定义截距与正则化约定，使用线性方程求解，避免显式求逆。
- 实现 fit/predict/state，约定零正则和奇异矩阵处理策略。

**验收条件：**

- [ ] 输出始终 (N,O)，不丢失目标顺序和单位元信息。
- [ ] 对已知线性关系可恢复合理预测；正则参数非法时失败。
- [ ] 与参考岭回归比较时对齐特征标准化、截距与损失缩放。

**验证方式：** 已知系数、共线特征、单/多输出、无正则边界、状态恢复和维度错误。
