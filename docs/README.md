# 项目文档导航

建议阅读顺序：

1. [需求清单](requirements.md)：R01-R22 的范围、依赖、交付与验收。
2. [架构约定](architecture.md)：模块职责、公共数据形状、接口和数据流。
3. [贡献流程](../贡献.md)：认领、建分支、开发、PR、合并与清理。
4. [研究与评估规范](research_protocol.md)：无泄漏实验与指标。
5. [数据集指南](../data/README.md)及[项目提案](../Group_12_EMGInsight_Visual_Proposal_Revised.pdf)。

`data_audits/` 存放各数据集审计结论，`experiments/` 存放按[实验模板](experiment_template.md)填写的记录，`report/` 存放最终报告与参考资料。[决策记录](decisions.md)保存架构和范围变更依据。

需求定义以 requirements.md 为准，接口以 architecture.md 为准，动态负责人/状态以 GitHub Issues 为准。现有规划不等于已经完成的功能。
