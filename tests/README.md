# 测试分区与约定

当前没有可执行算法测试；`python -m pytest` 退出码 5 表示未收集到测试，不能声称通过。每个功能需求随实现添加相应测试，R21 负责 CI 与整体集成环境。

- `unit/core/`、`datasets/`、`splitting/`、`preprocessing/`、`features/`、`models/`、`evaluation/`、`artifacts/`：对应模块的单元测试。
- `integration/`：三类合成任务的完整流程、保存恢复和离线推理。
- `fixtures/`：人工小样例或合成数据生成器，不放真实参与者数据。

使用 pytest 的临时目录保存测试产物，不写用户数据目录。数值测试明确容差与种子；默认测试不联网、不下载数据。真实数据检查单独启用并说明前置条件。

每个需求的具体测试见[需求清单](../docs/requirements.md)。公共契约、分组互斥、目标时间对齐和仅训练集拟合必须有实质验证；不要只验证“函数能够调用”。
