# 实验配置

`experiment.example.toml` 是 R02 的字段规格模板，包含刻意无效的 TODO/空值，当前不能用于训练。配置加载器应在训练前拒绝未填完整的配置。

数据审计完成后，正式配置分别放在 `gesture/`、`force/`、`fatigue/`。使用相对仓库根目录路径，机器专用设置放在被忽略的 `*.local.toml`。不得提交凭据或私人路径。

种子不能替代精确划分；`split.assignments_file` 指向 `data/splits/` 的经过确认的划分文件。目标名称、单位、对齐策略、通道编号与窗口参数必须来自数据审计。

首次运行模板中的默认策略只是约定，具体数值和可选字段由 R02 校验；新增字段时同时更新[架构](../docs/architecture.md)、模板、解析器及相关配置。当前没有训练命令，规划入口由 R15 实现。
