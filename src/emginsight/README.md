# Shared package

Import reusable code through `emginsight` after editable installation. Planned subpackages:

- `datasets/`: independent UCI, putEMG-Force, and Zenodo adapters.
- `preprocessing/`: recording-level filtering, windows, training-only transforms.
- `features/`: RMS, MAV, WL, and documented optional extensions.
- `models/`: custom NumPy classification/regression algorithms.
- `evaluation/`: grouped splits, task metrics, and comparisons.

See [shared interfaces](../../docs/research_protocol.md). These folders currently contain package placeholders, not working algorithms.
