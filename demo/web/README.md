# EMGInsight 网页演示

访问 [GitHub Pages 已发布版本](https://miemiess.github.io/ML_GruopWork/)，或生成本地快照后打开同目录的 `index.html`。左上角切换指力、手势和疲劳实验台，标题旁切换「观察案例」与「开发过程」。手势台还支持交互模拟。

## 训练过程视图

三个实验台顶部都有「训练过程」，用同一套分步动画讲解模型是怎么训练和挑选出来的。数值全部来自 `results/` 下已保存的实验表格，网页不重新训练。

1. **按人划分**：参与者编号先排成一池，再落入训练、验证、测试三组。
2. **训练人数**（手势、连续指力）：固定获选配置，只改变训练用户数，在验证用户上评分。每个人数抽 5 组用户，点为单次结果，实线为中位数。数据来自[学习曲线实验](../../results/learning_curve/report.md)。
3. **候选搜索**：按实验的评估顺序逐个点亮验证分数，阶梯线记录“当前最佳”，最后圈出获选模型；虚线按特征尺度等分组。
4. **留出评估**：获选模型与基线在测试用户上的成绩，以条形图对比。
5. **逐个用户**：每名测试用户一行，模型点从对照位置滑到模型位置，并标出是否优于对照。

纵轴统一为“越往上越好”；RMSE、MAE 等越低越好的指标会翻转坐标，刻度仍显示真实数值。每一步可点「表格」查看同一数据，「↻ 重播」重新播放动画，键盘左右方向键翻页。地址会记住步骤，例如 `force.html#continuous/training/3` 直接打开指力候选搜索。系统开启“减少动态效果”时直接显示终态；也可在地址加 `?still` 用于截图。

指力和疲劳台的「开发过程」中，“训练选型”和“留出评估”两步嵌入了同样的图。三档与疲劳的案例时间线改为上下两条色带，分别是实测（或评分）和预测，中间的橙色短条标出两者不一致的窗口。

## 手势信号实验台

在顶部选择「开发过程」，用「下一步」查看按用户划分、时域特征提取、逻辑回归概率曲线、kNN 邻居投票、随机森林的决策树及验证集选型。特征页可切换真实窗口的八个通道，并查看加入 WL 后如何从 16 维扩展到 24 维。三个模型的解释图使用同一个验证窗口。逻辑回归曲线只改变一项特征，其余保持窗口中的实际值。

每一步都可单独重播。点击数据组可查看规模，拖动波形可逐点累积特征，拖动概率曲线可改变单项特征，调整 k 可看邻居票数变化。决策树支持分次查看两个判断和森林结果，选型图可按特征组合切换验证记录。

特征页可点选 RMS、MAV 或 WL，查看真实采样值怎样一步步转换成特征。下一页组装 `X_train`，并用训练集的均值与标准差逐列转换。逻辑回归可切换线性得分、Softmax 概率和单特征曲线。最后一页保留训练特征与类别的热图、标准化参数、模型参数和随机森林的第一棵树节选。

默认定位到测试用户 09 的握拳窗口。拖动时间轴到最左侧再播放，即可观察这段记录中的静息、未标注区间及握拳。点击混淆矩阵可选取对应真值与预测的一个真实窗口。左侧手模始终显示，有标签时模拟对应动作，未标注时显示自然姿势。右侧展示模型根据肌电窗口预测的姿势。两侧随同一时间轴更新。

算法运行流程随回放自动高亮。暂停在有效窗口后，点击「逐步演示」可固定该窗口，依次查看重叠分窗、通道特征、标准化前后数值和六类概率。也可直接点击任一阶段阅读关键代码示意、项目源码和机器学习原理。逐步演示约 3.4 秒，用于讲解处理顺序。波形沿用原始记录时钟，预测和概率来自 C 实验模型。

切换到「模拟」，用 INPUT 手模下方的按钮选择六种动作。网页按虚拟 1 kHz 连续生成八路信号，切换时平滑混合两个动作的波形。每类模板取自最接近该类特征中位数的一个训练窗口。浏览器按 200 点窗长、100 点步长计算 RMS、MAV、WL，经训练集参数标准化后，使用 C 实验的随机森林推理。OUTPUT 手模跟随模型预测，混合过渡区间也会送进模型。

信号来自 Krilova 等的 [UCI EMG Data for Gestures](https://doi.org/10.24432/C5ZP5C)，授权 CC BY 4.0。

## 指力预测实验台

打开同目录的 `force.html`，或从手势实验台顶部切换。案例回放取自 D 实验选定的测试用户 46。拖动时间轴或点选 FORCE_1 至 FORCE_10，可以比较实测、已平滑预测与训练均值基线。开发过程的特征和五窗平滑示例沿用当前窗口，可切换尺度浏览全部 72 个验证候选，最后按目标或按用户查看留出结果。

## 生成快照和发布

指力台的模型选择器还可切换到「力度三档」与「两日力量变化」。三档案例同步显示实测档位和三个预测概率；跨日案例可选测试用户与动作协议，对照每次动作、两日中位数和最终变化值。开发视图可逐步查看保持段、十路权重、验证候选与测试误差。公共模型输出 putEMG 原始刻度。

肌肉疲劳台默认展示全试验四路模型，可切换独立测试用户及试验，逐窗对照预测与自感评分。训练视图比较候选模型和时间基线，开发视图展示四个阶段及逐人指标。切换至单路实验可以回放两名独立测试参与者的右肱二头肌记录。逐窗对照自感评分、预测等级和五项特征；开发视图可检查分窗、岭分类器的三个线性得分、验证选型及时间基线。

在项目根目录运行以下命令。手势导出需要 [C 实验](../../results/gesture/classification/report.md)使用的 UCI 原始数据、获选模型和结果表。指力导出需要 [D 回归实验](../../results/force/regression/report.md)保存的模型、案例特征缓存和结果表。

```powershell
.\.venv\Scripts\python.exe demo/web/export/prepare.py
.\.venv\Scripts\python.exe demo/web/export/force_export.py
.\.venv\Scripts\python.exe demo/web/export/build_pages.py
```

- `prepare.py` 读取模型卡验证保存的随机森林，并按已保存的逐窗预测核对回放数据。教学页读取 `validation.csv`，只拟合展示用的逻辑回归和 kNN 候选。只需刷新回放和模拟时，可加 `--skip-development`。
- `force_export.py` 读取回归模型和缓存，核对案例的窗口位置、调零后实测值及五窗平滑预测。
- `build_pages.py` 校验已有快照，并运行 `model_export.py` 生成三档、跨日与疲劳案例，运行 `training_export.py` 生成训练过程视图的数据（含学习曲线；若未运行 `python -m emginsight.learning_curve`，则跳过“训练人数”一步）。跨日使用 `results/runs/force/force_change_model.joblib` 核对逐次输出；疲劳使用 `results/runs/fatigue/single_channel_biceps/model.npz` 重算类别得分并核对预测。静态页面、快照、源码示例和校验清单一并打包到 `build/pages/`。打开其中的 `index.html` 可离线预览。

网页源码和导出脚本由主分支维护。生成的 JavaScript 快照在 `data/` 中，被 Git 忽略，随静态网站一同发布。发布目录列出的校验值可以追溯到对应的模型和实验报告。
